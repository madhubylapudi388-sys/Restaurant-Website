# Zaika Bistro - Restaurant Website

A clean, responsive, single-page restaurant website built for a college Web Development Activity assignment.

**Live Demo:** <paste link here>

---

## 📌 Project Overview
Zaika Bistro is a static restaurant landing page designed to showcase an authentic dining experience. The website features an appetizing warm color palette, intuitive navigation, and well-structured sections designed using pure HTML5 and CSS3 (Flexbox).

---

## ✨ Features
- **Responsive Navigation Bar:** Smooth jump links pointing directly to each section on the page.
- **Hero Banner:** Eye-catching gradient hero header introducing the restaurant name, tagline, and a prominent "View Menu" call-to-action button.
- **Interactive Food Menu:** 8 distinct dish cards with icons, appetizing descriptions, and prices in Indian Rupees (Rs.).
- **Special Offers:** 3 promotional discount cards ("Combo Deal", "Weekend Special", and "Student Discount") with voucher codes.
- **Customer Reviews:** 3 verified dining review cards with star ratings (`★★★★★`) and customer testimonials.
- **Contact & Location:** Complete address, telephone, email, operating hours, and an embedded Google Map.
- **Footer:** Clean copyright notice with closing credentials.
- **Mobile Responsive:** Built using a single clean `@media (max-width: 768px)` rule that stacks all Flexbox containers vertically for mobile screens.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic layout tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<ul>`, `<li>`).
- **CSS3:** Flexbox for alignment, transitions on hover, custom gradients, box shadows, and responsive media queries.
- **Hosting:** GitHub Pages.

---

## 🚀 How to Run Locally
1. Download or clone this repository.
2. Double-click `index.html` to open it in any web browser (Google Chrome, Firefox, Edge, etc.).
3. No build tools, servers, or external libraries are required.
